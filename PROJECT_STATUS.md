# CAMPUS ONE — Project Status

## Current build
Frontend-only static app using HTML, CSS and vanilla JavaScript. No Node.js, database or backend is required.

## Completed
- Home, Timetable, Bus, Canteen and Campus Map
- Official first-year syllabus section for the CSE-family / CSE + AI/ML label
- Semester I and Semester II syllabus browsing, search and expandable course details
- Official MDU H-Scheme 2025-26 PDF included in `assets/docs/`
- CAMPUS ONE AI updated to answer syllabus/course/unit/credit questions directly in chat
- Live date/time and Morning/Afternoon/Evening greeting
- Local frontend student profile/login
- Creator credits
- Responsive navigation and UI polish
- Report a Problem, Lost & Found and Suggest a Change removed

## Important data note
The supplied syllabus document is from M.D. University, Rohtak and states that the first-year H-Scheme is common to B.Tech programmes with branch-specific course variants. It explicitly maps CSE-family Mathematics-I/II and Semiconductor Physics variants to Computer Science Engineering and allied Computer Science branches. CAMPUS ONE uses the current A2 timetable label “CSE + AI/ML” for the corresponding CSE-family view; no additional AI/ML-specific first-year subject was invented.
