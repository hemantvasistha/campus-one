# CAMPUS ONE

**For the Students. By the Students. To the Students.**

A lightweight, frontend-only campus companion for BRCM College of Engineering & Technology, Bahal.

## Run

No Node.js, npm, database, API key or build step is required.

Open `index.html` in a modern browser. For the best local experience, use VS Code Live Server (or any simple static web server).

## Included

- Live date, time and time-based welcome message on the home page
- Timetable for Section A1 (CSE) and A2 (CSE + AI/ML)
- Verified morning bus routes and coordinators
- Verified canteen menu and supplied special notice
- BRCM Vidyagram Campus map with searchable 78-facility legend
- Syllabus, Notes and Library landing pages ready for official resources
- Frontend-only CAMPUS ONE Smart Assistant using the verified local data layer
- Local student profile/login using browser `localStorage`
- Creator Credits

## Important scope note

This version intentionally does **not** include Report a Problem, Lost & Found, or Suggest a Change. It also does not claim secure server authentication or real cloud AI. A real multi-user login/database and a production AI API can be added later if needed.

## Data policy

Campus facts displayed by the app are based on the documents/images supplied for the project. Where official information has not been supplied, the UI says so instead of inventing a value.
